# Freeline

**The live, verified map of free frontier AI.**

Freeline tracks which frontier AI models are free *and actually working right now* — every route carries a status (live / expiring / dead), a last-verified timestamp, and an honest record of routes that died. Verified beats listed.

Prototype board: https://kaiser0733.github.io/freeline/

Built for the Meta Global AI Developer Hackathon (Indie track).
